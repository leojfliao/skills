# Internal Tech Talk Toolkit

Three reusable Skills covering the full path of an internal company presentation: **decide how the system is drawn, decide how the story is told, then package it into a clickable deck**. The presentation Skill now has two modes: an operations deck (FinOps, metrics, solutions, delivery) and a commercial pitch deck built from open, publicly documented pitch frameworks.

> **Non-official notice.** This repository is a personal collection of general methods and assets. It is not an official HSBC brand guideline and is not published by HSBC. The visual layer uses only publicly verifiable brand characteristics. The deck includes a **redrawn representation of the HSBC Hexagon**, which is not an official asset (see "Brand Mark and create.hsbc"). No internal templates, official logo files, real customer names, or business data are included. Sources and the verification date are in `visual-system.md`.

**Language**: all documentation, sample copy, and generated deliverables are in English.

## The Three Skills

| Skill | Owns | Input | Output |
|---|---|---|---|
| `solution-architecture-diagram` | How the system is built | Component list, call relationships, deployment environment | One self-contained SVG architecture / solution diagram |
| `internal-share-narrative` | What to say, and in what order | Topic, audience, duration, existing material | Markdown narrative outline / retrospective story / speaker script / commercial pitch narrative + Q&A prep |
| `fintech-presentation` | How it looks, how data is displayed, and how it is navigated | Approved outline or script, plus verified figures for any chart | One self-contained interactive HTML deck (operations mode or pitch mode) with in-slide controls |

All three share the same visual conventions from `visual-system.md`. Recommended order: diagram → narrative → deck; any one can also be used on its own.

## What the Deck Shells Contain

`fintech-presentation/assets/deck-shell.html` is a **runnable 14-slide operations deck**, and `fintech-presentation/assets/pitch-deck-shell.html` is a **runnable 12-slide commercial pitch deck**. Neither is an empty scaffold. Open either directly in a browser; every figure is fictional and labelled "sample".

| Area | Example slides | Interactions |
|---|---|---|
| Opening | Cover, clickable agenda, three section dividers | Agenda cards jump to a chapter; angled red band on dividers |
| FinOps | Budget vs. actual, savings levers | Q1–Q4 switcher, highlight-variance toggle, hover / focus tooltips, expandable lever rows |
| Metrics | 12-month service trend, SLA posture | Four-series switcher, target-line toggle, tooltips, sortable table |
| Solutions | Option comparison matrix, reference architecture | Three option tabs with scored matrix, synchronous / asynchronous path switch, clickable tiers with detail panel |
| Delivery | Roadmap, risk register, closing | Selectable phases with exit conditions, sortable risk table, expandable control |
| **Pitch** | Thesis, problem / solution, why now, TAM / SAM / SOM, traction | Sizing-basis switch, traction-series switch, target toggle, selectable pain rows |
| **Pitch** | Unit economics, 2x2 competition, pricing, waterfall, tornado | Selectable rival detail, pricing-basis switch, scenario switch, sensitivity-driver switch |
| **Pitch** | Team, the ask, closing | Expandable milestones, one red focal total |
| Everywhere | Progress bar, TOC, overview, speaker notes | `← →` navigate, `Esc` overview, `N` notes, `F` fullscreen, `?` shortcuts, `#N` deep links, print expands all chart views |

Charts are generated by each file's own script from a small data block — no chart library, no CDN, no network request. Replace that data with verified figures before using a deck externally; with no verified data, use a table instead.

## Commercial Pitch Frameworks: Sources and Licence

The pitch mode absorbs **structure and layout vocabulary only** from the sources below. No upstream code, CSS, fonts, artwork, CLI scripts, or runtime is vendored, and no third-party brand name appears in a generated deck. Sources were checked on **2026-11-08**.

| Framework | Source | Status | What was borrowed |
|---|---|---|---|
| Sequoia "Writing a Business Plan" | `https://www.sequoiacap.com/article/writing-a-business-plan/` | Publicly published method | The 10-part order, one-sentence company purpose, explicit "Why now?" |
| YC seed deck / Seibel's seven questions | YC public founder guidance | Publicly published method | Traction on slide 4, action-title headlines, ~15-slide ceiling, founders-only team slide |
| **Presentable** — Enterprise / Investor | `https://github.com/haiwakatta/presentable` | **MIT** | Pyramid Principle, SCR, MECE, action titles; the TAM / SAM / SOM, waterfall, tornado and financial-tile *chart types* |
| **Opinionated 10-slide pitch deck** | `https://github.com/batkotron/pitch-deck-template` | **MIT** | The 10-slide order, bottom-up sizing, traction-first principle, pre-send checklist |
| Kawasaki 10 / 20 / 30 | Publicly published rule | Publicly published method | ~10 slides, ~20 minutes, 30pt-equivalent floor as an optional ceiling |
| Airbnb (2009) and Buffer (2011) seed decks | Publicly circulated examples | Public case studies | Sentence-length headlines, numbers instead of adjectives, four-number unit economics |

Prior art for the single-file HTML deck approach, recorded but not used as a structure source: `https://github.com/zarazhangrui/beautiful-html-templates` (MIT) and `https://github.com/SurgePix/ai-ppt-prompts` (MIT). No file from either is bundled.

**Attribution.** The two MIT projects are credited here even though MIT does not require it. A public method is cited as a method, never as a licence or an endorsement. Full framework orders, the layout / interaction mapping, content discipline, and acceptance lists live in `fintech-presentation/references/pitch-frameworks.md`. If you extend that file, keep the source register and the "structure only" boundary intact.

## Installation

Target platform: WorkBuddy, user-level Skills at `~/.workbuddy/skills/`. Copy the Skill directory as a whole into that location. The three Skills are independent, so you may install only one. Installation is performed only after you confirm it; this repository ships no auto-installer.

## Fallbacks and Boundaries

| Situation | Behaviour |
|---|---|
| Cannot generate an HTML deck | Output a structured Markdown slide-by-slide outline, marked "not rendered" |
| Cannot generate an SVG diagram | Output a component list + relationship table + layered Markdown table, marked "not drawn" |
| Insufficient input | List what is missing and stop; no invented components, numbers, or conclusions |
| Material contains non-public data | Ask for redaction before continuing; do not copy the source text into the output |
| Verified figures are missing | Use a table, mark `TBD`, or omit the chart; never ship sample numbers as real |
| User asks to copy an upstream template verbatim | Decline the verbatim copy; offer a structural reinterpretation under this visual system |
| User wants PPTX, long-read, or batch PDF conversion | Route to the corresponding existing Skill above; do not force it |

## Out of Scope

No PPTX / Word / PDF deliverables, no UI mockups, no flowcharts or sequence diagrams, no live data sources, no auto-publishing or hosting, no official HSBC brand assets (the Hexagon in the decks is a redraw; obtaining official assets requires signing in to `create.hsbc` yourself), and no vendored third-party template code, fonts, or artwork.
